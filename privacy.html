Privacy Policy

Last updated: 26 October 2026

Studio Publisher ("the tool") is used only by its owner to publish the owner's own videos to the owner's own TikTok accounts.

Information we access

  • When the owner authorizes the tool with TikTok, TikTok provides an access token and basic account information (open ID, display name, avatar) for that account.
  • The tool reads the status and public metrics (such as view, like and comment counts) of videos it published.

How we use it

Only to upload and schedule the owner's videos and to report how they perform to the owner. We do not sell, share or use this information for advertising.

Storage and security

Tokens are stored on the owner's private computer in a file readable only by the owner. Nothing is stored on public servers. Tokens can be revoked at any time from TikTok's settings (Security → Manage app permissions).

Other users

The tool does not collect or process data about any TikTok user other than the authorizing account owner.

Deletion

To delete all data, revoke the tool in TikTok settings; the owner then deletes the local token file. Requests: vimalwebstudio@gmail.com.
